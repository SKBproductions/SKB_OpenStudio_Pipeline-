# SKB OpenStudio Pipeline

**SKBproductions, LLC — AI-Powered Black Cinema**

SKBproductions combines independent filmmaking experience with modern AI production tools to develop original Black cinema. This public repository documents the studio's evolving production pipeline, organizational standards, and safe reusable templates.

## Studio focus

- **The Dealbreaker** — crime-procedural expansion of the *Night Time People* world
- **Night Time People** — urban crime and nightclub drama
- **The 25th Dynasty** — historical African docudrama
- **Borsalino-Style** — 1940s-inspired noir storytelling

## What this repository demonstrates

The OpenStudio Pipeline is being developed to support a repeatable path from concept to completed film:

1. Story and scene planning
2. Character and visual continuity
3. Prompt and generation records
4. AI-assisted image, video, voice, and sound production
5. Editorial review and approval
6. Marketing, release, and archive records

This repository is currently a **public showcase and documentation space**. It is not the storage location for complete productions or confidential material.

## Repository structure

- `docs/` — public production and security documentation
- `projects/` — safe, high-level project records
- `templates/` — reusable character, scene, and generation-record templates
- `workflows/` — non-secret workflow documentation and future automation examples

Large media, unreleased screenplays, private character references, API credentials, and business records should remain outside this public repository.
