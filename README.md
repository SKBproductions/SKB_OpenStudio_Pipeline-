SKB Open Studio Pipeline

🎬 SKBproductions, LLC is building a new era of AI-Powered Black Cinema — reimagining history, culture, and storytelling through modern AI tools.

This repo contains the full creative pipeline for three major series:

Borsalino-Style — 1940s noir, Chicago crime world

The 25th Dynasty — Ancient Nubia, King Kushta, Prince Piye

Night Time People — Urban crime, nightclub underworld

Use this repository as a structured, open-source–friendly workspace for organizing scripts, prompts, storyboards, renders, audio, thumbnails, and marketing material.## 📦 Structure

```
SKB_OpenStudio_Pipeline/
├─ projects/
│  ├─ Borsalino-Style/        # Noir series: Duke, Ava, Chicago 1940s
│  ├─ The-25th-Dynasty/       # King Kushta, Piye, desert epics
│  └─ Night-Time-People/      # Urban crime drama, nightclub owners
├─ assets/                    # Reusable images, prompts, LUTs, fonts, refs
├─ audio/                     # VO, music, SFX
├─ video/                     # Sources, proxies, renders
├─ marketing/                 # Thumbnails, pitch decks
├─ templates/                 # Prompt + checklist templates
├─ automation/                # Scripts or notes for Huginn/GitHub Actions
├─ docs/                      # Notes, tutorials, pipeline diagrams
└─ scripts/                   # Utility scripts (e.g., renamers, converters)
```

> Tip: Keep **heavy media** (e.g., `.mp4`, `.wav`) managed via **Git LFS**. See below.

🚀 How to Use This Repo

Clone or download the repository

Each series has its own folder under /projects

Place all reusable assets (LUTs, thumbnails, image prompts) under /assets

Use /templates for:

prompt templates

cene checklists

thumbnail templates

Use /marketing for export-ready thumbnails and pitch decks

Use /automation to automate repetitive tasks
